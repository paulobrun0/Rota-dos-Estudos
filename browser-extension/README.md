# Ritmo · Marcações de estudo

Extensão original e independente, para capturar uma seleção de texto na página ativa, guardar notas e exportar JSON. Os dados ficam no armazenamento local do navegador. Não solicita credenciais nem envia registros a um servidor.

Para uso local, extraia o pacote e carregue a pasta em `chrome://extensions`, usando **Carregar sem compactação**. A captura exige uma ação no botão da extensão; não há permissão permanente para todos os sites. Páginas internas, protegidas e o leitor nativo de PDF podem impedir a captura.

Em **Ferramentas** na plataforma, selecione o assunto e importe o JSON exportado. Guarde uma exportação antes de remover a extensão ou trocar de navegador.
